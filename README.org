* CSNAnalysis: Tools for creating, analyzing and visualizing Conformation Space Networks

CSNAnalysis is a Python package for network-based analysis of molecular dynamics trajectories.
Initialize a ~CSN~ object from a matrix of transition counts between molecular conformations to
access a unified interface for computing network properties, analyzing kinetics, and exporting
visualizations.

CSNAnalysis connects enhanced sampling algorithms (e.g. [[https://github.com/ADicksonLab/wepy][wepy]]), clustering programs,
graph analysis (e.g. [[https://networkx.org][NetworkX]]), and
graph visualization programs (e.g. [[https://gephi.org][Gephi]]).

* Quick start

#+begin_src python
  import scipy.sparse
  from csnanalysis.csn import CSN

  # Load a count matrix (numpy array, scipy sparse, or list of lists)
  count_mat = scipy.sparse.load_npz('matrix.npz')

  # Build the CSN and trim poorly-sampled states
  csn = CSN(count_mat, symmetrize=True)
  csn.trim(by_inflow=True, by_outflow=True, min_count=20)

  # Compute steady-state weights
  weights = csn.calc_eig_weights()

  # Compute committor probabilities between two basins
  committors = csn.calc_committors([basin_A, basin_B])

  # Compute mean first passage times to a set of sink states
  mfpt, fptd = csn.calc_mfpt(sinks=basin_A)

  # Export to Gephi for visualization
  import networkx as nx
  nx.readwrite.gexf.write_gexf(csn.graph.to_undirected(), 'network.gexf')
#+end_src

* Features

- *Network construction* — build a ~CSN~ from numpy arrays, scipy sparse matrices, or lists of lists,
  with optional symmetrization of the count matrix

- *Trimming* — remove poorly-connected or poorly-sampled states via inflow/outflow connectivity
  to the most-sampled node, with optional minimum count threshold

- *Steady-state weights* — compute equilibrium populations via the leading eigenvector or
  iterative matrix multiplication

- *Committor probabilities* — compute forward-committor probabilities to an arbitrary number
  of basins using iterative matrix multiplication or direct linear algebra (2-basin only)

- *Mean first passage times* — compute MFPTs and first passage time distributions (FPTDs) from
  all states to a set of sink states, with support for source-averaged MFPTs

- *Hub scores* — quantify the degree to which a set of intermediate states mediates transitions
  between two communities (see [[https://pubs.acs.org/doi/full/10.1021/ct300537s][Dickson & Brooks, JCTC 2012]])

- *Eigenvectors* — extract the slowest dynamical modes of the transition matrix

- *Visualization* — color nodes by committor probability and export GEXF files for Gephi
